# Изгиб Питона

Классическая «Змейка» на Python и Pygame с объектно-ориентированной логикой.
Поле — 640 × 480 пикселей, клетка — 20 × 20, скорость — 20 шагов в секунду.

## Запуск

Нужен Python 3.10 или новее и графический рабочий стол.
Проект проверен на Python 3.14. Зависимость `pygame-ce` — поддерживаемая
версия Pygame с тем же импортом `pygame` и готовыми сборками для Python 3.14.
Не устанавливайте `pygame` и `pygame-ce` одновременно в одно окружение.

В директории проекта:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python the_snake.py
```

В Windows активация окружения: `.venv\Scripts\activate`.
Если `.venv` уже создана и зависимости установлены, достаточно активировать
окружение и запустить `python the_snake.py`.

## Управление и правила

- Стрелки поворачивают змейку. Разворот назад запрещён.
- Esc или закрытие окна завершают игру.
- Яблоко увеличивает длину на один сегмент и появляется вне тела змейки.
- Через границы поля змейка переходит на противоположную сторону.
- Самоукус начинает новый раунд: одна голова в центре, случайное направление.
- При заполнении всего поля также начинается новый раунд.
- Заголовок окна показывает длину и рекорд текущего запуска.
  Между запусками рекорд не сохраняется.

## Устройство

В `the_snake.py` находятся базовый класс `GameObject`, его наследники `Apple`
и `Snake`, обработчик клавиатуры `handle_keys` и игровой цикл `main`.
При движении рисуется только новая голова и стирается покинутый хвост;
всё поле очищается только в начале раунда. Параметры поля, цвета и скорость
заданы константами в начале модуля.

## Проверки

В активированном окружении:

```bash
python -m pytest
python -m flake8
python -m pip check
```

Для запуска тестов в Linux без экрана и звукового устройства:

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy python -m pytest
```

Тесты проверяют структуру классов, переходы через все границы, рост,
самоукус, размещение яблок, заполнение поля, управление и отрисовку.
Локальные каталоги `.venv/` и `.tmp/` исключены из Git.
